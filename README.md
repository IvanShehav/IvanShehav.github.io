# Интерактивное резюме: Иван Шехавцов

Сайт: https://ivanshehav.github.io

Статический сайт без сборки: HTML, CSS и немного JavaScript. Проекты открываются в мини-окнах с живыми демо.

## Как править

- Все тексты (RU и EN), проекты, опыт и навыки лежат в `assets/data.js`.
- Мини-демо проектов: `assets/demos.js`.
- Оформление: `assets/styles.css`. Поведение страницы: `assets/app.js`.
- Новый проект добавляется записью в `data.js` (id, тексты, навыки, ссылка) и, если нужно демо, функцией в `demos.js`.
- Проверка стиля текстов: `python3 scripts/check-style.py`.
- Изменения вносятся по OpenSpec: описание в `openspec/`, история в `openspec/changes/archive/`.

## Что намеренно не опубликовано

- Номер телефона и PDF-резюме, где он указан.
- Токены, внутренние данные МИС и медицинские данные.
- Прогнозные цифры в демо помечены как прогнозные.
